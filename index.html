Paste it into Outlook
New Outlook (Windows) and Outlook on the web
  1. Click the gear icon, then Account → Signatures.
  2. Click + New signature and name it "CSG".
  3. Click in the editor box and press Ctrl+V.
  4. Under Select default signatures, pick "CSG" for new messages and for replies/forwards, then Save.
Classic Outlook (Windows)
  1. Go to File → Options → Mail → Signatures…
  2. Click New, name it "CSG", and paste into the editor with Ctrl+V.
  3. On the right, set it as the default for new messages and replies/forwards, then click OK.
Outlook for Mac
  1. Go to Outlook → Settings → Signatures.
  2. Click +, name it "CSG", and paste into the editor with ⌘+V.
  3. Close the editor to save, then choose it as the default for new messages and replies.
  4. Mac signatures don't sync, so repeat this on each Mac you use.
Outlook on iPhone or Android
  1. The mobile app only takes plain-text signatures. Use your name, title and phone, or leave it off.
